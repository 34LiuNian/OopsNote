# 前端信息架构与交互

状态：题目编辑、知识树选择、保存语义的现行约定

更新：2026-08-27

视觉 token 仍以 [DESIGN.md](../DESIGN.md) 为准。本文约定**何时用整页、何时用模式、何时用弹层**，以及分类字段与知识树的控件边界。工程入口见 [AGENTS.md](../AGENTS.md)。

## 1. 决策顺序

改排版或交互时按这个顺序，不要先画双栏或先加字号：

1. 这块服务的是「扫一眼 / 改几个字」还是「待很久」？
2. 字段回答的是卷面定位、目录节点，还是自由备注？
3. 展开后主页面会不会变长、挡住保存、其它行或附图？
4. 默认展开有没有打开「当前真正关心的那条路径」？
5. 不可选状态有没有还占着可选控件的位置？
6. 两个「保存」是不是同一件事？

高频短路径占用稳定主页；耗时长的工具进入有边界的工作表面。

## 2. 表面类型

| 表面 | 用途 | 例子 |
|------|------|------|
| 稳定主页 | 阅读与短编辑，高度可预期 | 题目校对：左信息轨 + 题干/选项 + 附图折叠预览 |
| 显式模式 | 同一对象上的深度工作，整页换任务 | 附图沉浸：只读题面 + 附图工作台 |
| 弹层 / 对话框 | 高树或临时多选，不撑开文档流 | 单题「选择知识点」 |
| 常驻侧栏 | 配置阶段持续筛选 | 正式组卷知识树（cascade） |

不要把附图工作台或完整知识树嵌进校对页文档流。`max-height` 裁切不能代替换表面。

## 3. 题目编辑

`frontend/components/ProblemEditPanel.tsx` 只有两种模式。

### 校对（默认）

```text
页眉：编辑题目 / 关闭
左轨：题号、章节、来源、难度、区段总题数
主栏：题干、选项、分类摘要
下方：附图折叠预览，或无图时的添加入口
页脚：文字草稿状态 / 取消 / 保存修改
```

- 元数据留在左轨，不放到题干上方。
- 打开编辑时附图一律先折叠，不因「有图 / 需复核」自动展开工作台。
- 「进入改图」进入沉浸；无附图走「添加附图」，添加后进入沉浸。

### 附图沉浸

```text
页眉：附图沉浸 / 编辑文字 / 退出改图 / 关闭
上方：只读题面（ProblemContent，接近非编辑态）
下方：完整附图工作台
页脚：附图状态 / 编辑文字 / 退出改图
```

- 只读题面用于对照排版，不放 textarea。点「编辑文字」回到校对。
- 沉浸态页脚**不**放主按钮「保存修改」。
- 若带着未保存文字草稿进入沉浸：轻提醒 + 次要「保存文字」，不升成主 CTA。

## 4. 保存语义

| 对象 | 何时写入 | 出现位置 |
|------|----------|----------|
| 题号 / 章节 / 来源 / 难度 / 题干 / 选项 / 标签 | 校对页脚显式保存 | 「保存修改」 |
| 附图启用、类型、布局、裁剪、色调 | 操作当时即时持久化 | 工作台控件本身 |
| TikZ 候选版本 | 「编译并保存」或 AI 任务提交 | 源码区 / AI 区 |

禁止用同一个主 CTA 覆盖这两类写入。

## 5. 分类字段

三种数据和题目「章节」不是同一类东西，控件不能共用。

| 字段 | 含义 | 控件 |
|------|------|------|
| 知识体系 | 学科知识树叶子，不可在编辑页新建 | 路径芯片 +「选择知识点」对话框，`selectionMode="leaf"` |
| 错题归因 | 扁平、可复用、可新建 | 空则一行「添加」；建议列表已有值在前，新建在后 |
| 备注标签 | 自由文本 | 默认折叠 |
| 章节 | 原卷印刷章节，用于卷面定位和难度区段 | 左轨文本，**不是**知识树一级 |

知识树 path[0]（如「函数与导数」「力学」）是学科分组；`chapter` 是这道题印在哪一章下面。二者不互相替代。教材章节树 `chapter_trees.json` 仍为 reserve，不参与检索。

目录与存储约定见 [tag-catalog.md](tag-catalog.md)。

## 6. 共享知识树

唯一实现：`frontend/components/knowledge-tree/`。

| 调用方 | `selectionMode` | 容器 |
|--------|-----------------|------|
| 正式组卷筛选 | `cascade`，父级可整枝勾选 | 组卷侧栏，常驻 |
| 单题编辑 | `leaf`，只有叶子可选；上限 6 | 对话框，树在弹层内滚动 |
| 题库筛选（产品 L1） | `cascade`，父级可整枝勾选；数量不封顶 | 学科 → 知识点弹层 → 错题归因 |
| 题库筛选二级 | 侧栏「更多筛选」，有值自动展开 | 来源、日期、备注标签 |

题库筛选本身就是找题的 L1，不是「知识树的一级目录」。题库与 AI 渠道的 L1 同宽 312px（目录/筛选上下文）；组卷 L1 为 320px，因为知识树常驻。第一屏只放学科、知识体系、错因。学科与当前选中值同一行，收起是普通文字，不要浮起底和阴影。悬停时在浮层里由一个变成多个并带动画，浮层不占下方文档流，可画出侧栏边界。触控改为点按展开。选择知识点弹层里的学科直接铺开，不复用侧栏收起态。知识入口始终可点：无学科时同一个弹层先选科再出树。题库与组卷同为 cascade：勾选父级等于选中其下全部叶子。题库查询传压缩后的 `knowledge_node_id`，由后端展开成叶子标题再任意命中（OR），不要把整枝叶子展开进 `knowledge_any`。单题编辑才是 leaf。来源和日期是二级，不要和第一屏平铺。

共享规则：

- 自动展开只打开**已选叶子的祖先链**，不按深度（例如前两层）盲目展开。
- 叶子身份只以**过滤前的源树**计算。搜索把父级裁成空 `children` 时，它仍是父级；叶子模式不得出现勾选框，级联模式仍可整枝勾选。
- 叶子模式：父级只有展开箭头，不占复选框列；叶子才有勾选框。
- 级联模式：父级同时有箭头和复选框；叶子用占位对齐勾选列。
- 用箭头 / 勾选框区分浏览与选择，不用字号或字重区分叶子与父级。缩进只表达深度。
- 数量上限是调用方政策：单题默认 6 个叶子，题库筛选传 `maxSelected={null}`。禁止在该对话框新建知识标签。
- 单题编辑的值是叶子标题。题库 cascade 的值是压缩后的目录节点 ID，查询走 `knowledge_node_id`；题目上仍然只保存叶子标题。

组卷配置页的筛选职责仍见 [paper-workflow.md](paper-workflow.md)。

## 7. 学科

`TaskRecord.effective_subject()` 是目录与知识树的学科真源。详情投影输出这一份 `subject`。

- 空白任务学科与空白题目学科在 Core 写入时互相补齐；别名收成 canonical key。
- 冲突的两个非空学科不在存储层静默覆盖；有效学科仍以任务为准。
- 前端只读投影后的 `problem.subject` / `task.subject`，禁止再写 `task.subject || problem.subject`。

## 8. 检查清单

改题目编辑、组卷筛选、标签或任何「阅读 + 工具」混合界面时：

- [ ] 高频路径仍是稳定主页，长工具进模式 / 弹层 / 侧栏。
- [ ] 控件与数据性质一致（叶子目录、错因、备注、印刷章节分开）。
- [ ] 展开不穿过保存栏、其它字段或附图。
- [ ] 默认展开落在当前选中路径上。
- [ ] 不可选节点不占可选控件的位置。
- [ ] 叶子模式的可选性来自过滤前的源树，搜索不得把父级变成可勾选项；级联模式父级始终可整枝勾选。
- [ ] 主按钮只有一种写入语义。
- [ ] 知识树走共享模块，而不是页面内再复制一棵树。
