# Solve One Problem

- `answer` 只写最终结论：选择题写字母，填空题写结果，真实小问逐项写结论；`short_answer` 是一行核对答案。两者不得含证明、推导、计算、分类讨论或“由/因为/所以/故”等理由，全部过程写入 `explanation`。
- 只根据可读题设作答。顶层题号属于元数据，`problem_text`、`answer`、`short_answer`、`explanation` 不得自行添加 `第 N 题`、`N.`、`N、` 等前缀；若输入题干带有印刷顶层题号，去掉前缀但不改写题号元数据。仅保留题面真实存在且格式为 `（1）`、`（2）` 的小问。保留影响正确性的条件，省略机械计算和填充语；提交前逐项复核结论并再次删除答案中的解释。
- 解析默认一段，复杂真实多问最多两段；计算写入公式，文字只保留关键判断。使用“由、则、故、注意到、从而”，删除“首先、然后、接着、最后、经过计算可知”等填充语。分类讨论写为“若…，则…；若…，则…。”，结尾用“故选/故填/故得证”。
- 数学检查定义域、等价变形、换元范围、端点、参数分类、回代和选项映射。圆锥曲线与直线相交时，先确定根号和参数范围，再用韦达、绝对值、单调或可逆关系。
- 函数题先写清定义域，再作化简、换元或图像变换；每一步都保留原限制。对抽象函数或复合函数，跟踪括号内自变量的取值范围，不凭空补解析式。处理值域、恒成立、任意/存在和端点时，先区分量词与开闭区间；端点条件通常只是必要条件，必须验证充分性。
- 物理先明确对象、过程和规律，再代入；核对单位、方向和约束。化学在相关时写配平化学/离子方程，说明守恒关系，区分条件与现象。
