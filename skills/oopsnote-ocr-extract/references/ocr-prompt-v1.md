# OCR 提取 — 详细指令（V2）

你收到的是一道**已被确认的错题图片**。不需要判断对错，直接提取结构化题面。

## 学科识别

根据题目内容自动判断学科（不依赖外部提示）：

| 学科 | 特征关键词 |
|------|-----------|
| **math** | 代数式、方程、函数、几何图形、三角函数、向量、概率、统计、微积分 |
| **physics** | 力、速度、加速度、电路图、光路、电磁场、热力学、单位（m/s, N, J） |
| **chemistry** | 化学式（H₂O）、方程式、元素周期表、有机物结构式、实验装置 |

## JSON 输出格式

```json
{
  "subject": "math",
  "question_type": "解答题",
  "problem_text": "已知 $f(x) = x^2 - 2ax + 3$，$x \\in [1, 3]$，求 $f(x)$ 的最小值。",
  "options": []
}
```

### 字段说明

| 字段 | 必须 | 说明 |
|------|:----:|------|
| `subject` | ✅ | 仅限 `math` / `physics` / `chemistry`（英文）|
| `question_type` | ✅ | `单选题` / `多选题` / `填空题` / `解答题`（中文）|
| `problem_text` | ✅ | 完整题面，Markdown + LaTeX |
| `options` | ❌ | 选择题时必填，数组；其他题型可省略或空数组 |

## 格式要求

### 数学公式
- 行内公式用 `$...$`，独行公式用 `$$...$$`
- 注意反斜杠转义：LaTeX 中的 `\` 在 JSON 中需写为 `\\`

### 填空题
- 空位用 `\\underline{\\hspace{2cm}}` 表示

### 选择题
- 选项单独列出，不混入题干
- 选项格式：`["A. $x=1$", "B. $x=2$", ...]`

### 多小问题
- 使用 `\\begin{enumerate} \\item[(1)] ... \\end{enumerate}` 包裹
- 每个 `\\item[(1)]` 代表一个小问

### 化学式
- 可用 `\\ce{...}`（mhchem 包）或手写 LaTeX
- 有机物结构式保留文本描述即可

## 约束

- **不输出题号**（如 "6."、"第3题"）
- **不输出来源**（如 "2024某地一模"）
- 图片模糊无法识别 → 只输出 `{"error": "图片质量不足，无法提取"}`
- 输出必须是纯 JSON，不包含多余文本或 Markdown 包裹
- 只输出一道题，不批量输出
