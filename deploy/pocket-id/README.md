# Pocket ID Deployment

Pocket ID is the OIDC identity provider for the production deployment.

1. Copy `pocket-id.env.example` to the ignored `pocket-id.env` on the server.
2. Create `secrets/encryption_key` with a random value generated by
   `openssl rand -base64 32`. Keep this value for the lifetime of the database.
3. Start the `pocket-id` Compose service. It is intentionally reachable only at
   `127.0.0.1:14110`; the reverse proxy (1Panel Caddy) owns the public auth route.
4. Complete the initial administrator setup at the public HTTPS URL.

The persistent `pocket-id-data` Docker volume contains the SQLite database and
OIDC signing keys. Back it up together with the encryption-key secret.
